# 홈 화면 타이포그래피 정리 계획

- 작성일: 2026-08-21
- 상태: 사용자 요청으로 타이포그래피 적용 롤백 완료 · 레이아웃/상호작용 규칙은 유지
- 범위: 홈 화면의 텍스트 크기·굵기·색상·행간 체계

## 현재 문제

홈 화면은 공통 `home-*` 클래스와 화면별 Tailwind 유틸리티가 섞여 있어 행사 카드, 게시판 위젯, 캘린더, hero의 제목·본문·메타 텍스트가 서로 다른 크기와 굵기로 보일 가능성이 있다. 특히 `font-bold`·`font-semibold`·raw `text-*`가 같은 위계 안에서 반복되어, 무엇을 먼저 읽어야 하는지 화면마다 달라진다.

이번 요청에서 지정한 캘린더 날짜 숫자·bar·툴팁·다가오는 일정 제목의 국소적인 크기 조정은 기능 가독성을 위한 예외로 먼저 적용했다. 이후 사용자는 전역 타이포그래피 적용 결과가 얇고 크게 보인다고 판단해, 타이포그래피 토큰 적용만 롤백하고 홈 레이아웃·드롭다운·탭바 등은 유지하도록 정정했다.

## 이전 승인안 (현재 타이포그래피에는 적용하지 않음)

### 1. 홈 전용 의미 토큰을 하나의 기준으로 통합

`apps/web/src/styles/tokens.css`에 홈 화면 역할별 토큰을 두고, 컴포넌트에서 raw font size/weight를 직접 섞어 쓰지 않는다.

| 역할 | 제안 크기 | 제안 굵기 | 용도 |
| --- | ---: | ---: | --- |
| Hero title | `clamp(2rem, 3.2vw, 3rem)` | 650 | 브랜드 문구. 단, 본문과의 대비를 위해 한 화면에 한 번만 사용 |
| Event title | `1rem` | 600 | 행사 카드 제목 |
| Event description | `0.8125rem` | 400 | 행사 설명·요약 |
| Board title | `0.8125rem` | 400/500 | 게시판 위젯 제목. 고정 공지만 500 |
| Calendar title | `0.875rem` | 600 | 월 제목·다가오는 일정 제목 |
| Metadata | `0.6875rem` | 400/500 | 날짜, 상태, 보조 정보 |

실제 값은 현재 캡처와 390px·1280px·1920px 렌더링을 비교해 ±1px 범위에서 조정한다. `font-black`과 `font-extrabold`는 브랜드 hero처럼 의미가 있는 예외 외에는 사용하지 않는다. 현재 적용은 hero 브랜드·행사 카드·게시판 위젯·캘린더 제목과 메타에 역할 토큰을 사용하며, 일반 본문은 선택·복사가 가능하도록 페이지 전체 `select-none`을 사용하지 않는다.

### 2. 위계와 색상 규칙

- 제목은 `--ui-text-strong`, 본문은 `--ui-text-body`, 메타는 `--ui-text-muted`를 기본으로 한다.
- 초록색은 active, link hover, 상태 의미에만 사용하고 일반 제목·본문에 반복하지 않는다.
- 행사 카드의 제목·설명은 각각 최대 2·3줄로 고정하고, 줄바꿈 때문에 카드 높이가 달라지지 않게 한다.
- 게시판 위젯은 행간과 날짜 컬럼을 고정해 8줄이 같은 리듬으로 보이게 한다.
- 캘린더 bar 안의 텍스트는 작은 크기와 한 줄 ellipsis를 유지하되, tooltip에는 원문을 줄이지 않는다.

### 3. 반응형 규칙

- 390px에서는 제목을 줄이기보다 2줄까지 허용하고, 메타를 축소한다.
- 768px 이상에서는 카드 제목 크기를 유지하고 카드 폭만 늘린다.
- 1280px 이상에서 화면 폭이 커져도 제목 크기를 계속 키우지 않고 `clamp` 상한으로 제한한다.
- 글자 크기 변경이 카드·캘린더·게시판의 레이아웃 시프트를 만들지 않는지 확인한다.

### 4. 검증 기준

- 데스크톱 1280×720, 와이드 1920px, 모바일 390px에서 위계가 동일하게 읽힌다.
- 본문·메타 대비를 유지하고, 키보드 focus-visible 상태와 겹치지 않는다.
- 한국어/영문 전환에서 제목·설명·날짜가 같은 역할 토큰을 사용한다.
- `font-*` 직접 사용을 홈 컴포넌트에서 검색해 의도하지 않은 예외를 제거한다.

## 적용 기록

- 2026-08-21 승인 완료: `apps/web/src/styles/tokens.css`에 홈 역할별 크기·굵기 토큰을 추가했다.
- `styles.css`에 hero/event/board/calendar 의미 클래스와 최신 복구 기준의 행사 카드 높이 토큰(데스크톱 약 330px, 모바일 약 260px)을 추가했다.
- 임의 색상·그라데이션은 홈 컴포넌트의 긴 Tailwind 클래스 대신 CSS 역할 클래스에 모았다.
- 홈 전체의 텍스트 선택 차단은 제거하고, 드래그 중인 캐러셀 viewport에만 일시적으로 선택 방지를 적용한다.
- 최신 비율 복구 이후 행사 카드는 데스크톱 약 330px, 모바일 약 260px로 고정해 수정 전 캐러셀의 리듬을 유지한다. 하단 게시판:캘린더 폭만 4:6으로 예외 적용한다.
- 2026-08-21 최신 정정: 위 역할 토큰의 적용을 롤백했다. 현재는 제목·본문·메타의 기존 시각 계층을 사용하며, 레이아웃·상호작용·컴포넌트 구조는 되돌리지 않는다.
