# UI 표기 규칙

## 일정 날짜와 시간

행사·설문·달력처럼 사용자가 일정을 빠르게 훑는 화면은 아래 형식을 사용합니다.

| 상황 | 형식 | 예시 |
| --- | --- | --- |
| 올해 날짜 | `MM.DD` | `07.08` |
| 다른 연도 날짜 | `YYYY.MM.DD` | `2027.01.03` |
| 시간이 필요한 일정 | `MM.DD HH:mm` | `07.08 14:30` |
| 같은 날 시간 범위 | `MM.DD HH:mm–HH:mm` | `07.08 14:30–16:00` |
| 날짜 범위 | 시작과 종료를 `–`로 연결 | `07.08–07.10` |

- 월·일·시·분은 항상 두 자리로 씁니다.
- 시간은 24시간제를 사용합니다.
- 설문 마감일도 일정 날짜 규칙을 따릅니다.
- 응답 제출 시각, 수정 시각, 감사 로그 같은 기록 시각은 연도를 생략하지 않고 `YYYY.MM.DD HH:mm`으로 표시합니다.
- 구현에서는 `apps/web/src/lib/schedule-date.ts`의 공통 포맷 함수를 사용하고 화면별 문자열 조합을 만들지 않습니다.

## 카드 텍스트

- 목록 카드 제목은 최대 두 줄, 설명은 최대 두 줄로 표시하고 넘치는 내용은 말줄임표로 처리합니다.
- 카드 높이는 제목이나 설명 길이에 따라 깨지지 않아야 하며, 날짜와 상태 정보는 카드 하단에 고정합니다.
- 서버가 행사 이미지를 제공하지 않는 현재 계약에서는 사이트 기본 행사 이미지를 사용하고, 설문은 설문 전용 그래픽 대체 이미지를 표시합니다.
