# UI 검증 (2026-09-12)
- Chrome 실제 Google Forms의 응답 요약/질문/개별 보기 구조를 읽기 전용으로 확인.
- 로컬 Chrome: 설문 더보기 열기 전후 h1 X 좌표 608.4000244140625로 동일.
- 국/영문 설명 Y 좌표가 동일하며 제목 툴바 공간에 함께 반응.
- 포커스 해제 시 toolbar visibility hidden, 160ms grid transition 후 높이 0. 편집/선택 카드 각 1개 유지.
- 다른 섹션으로 이동하면 편집/선택 카드 각 1개. 기존 이중 인코딩 값은 &로 표시.
- 과비 상태 라벨 클릭 후 aria-expanded=false. 실제 버튼 클릭 후 true.
- 합성 익명 응답 A/B 각 1건: 요약 각50%, 질문별 묶음, 개별 응답 B 선택 및 disabled 확인.
- 임시 검증 설문/응답은 전용 UUID로 생성 후 정리.
- 웹 타입 검사 및 프로덕션 빌드 통과.
- 응답 더보기: CSV 다운로드, 현재 보기 인쇄, 새로고침. Google Forms의 이메일 알림·저장 위치 변경·전체 응답 삭제 기능은 이번 구현에 포함하지 않음.
- 50개를 넘는 질문별 답변 묶음은 현재 페이지 범위이며 안내문에 명시. 요약 통계는 전체 응답 기준.
